# Convenciones de estructura del proyecto

Al crear o modificar código en este proyecto:

1. Usa HTML5 y Bootstrap para la estructura y los componentes de la interfaz.
1. Usa `Biblia.json` como fuente de datos para la información bíblica.
2. La se trabajara como base un archivo  `index.html`, `Biblia.json`,`index.js` y `style.css`
3. Coloca todos los estilos en `style.css`; no agregues estilos en línea ni bloques `<style>`.
4. Coloca todo el código JavaScript en `index.js`; no agregues JavaScript en línea ni bloques `<script>` con código.
